# ecommerce
an Oop based cli script for handling shop inventory and simulating user transactions 
This script can calculate transactions across shops, allow you to add custom items with their price, modify the shop size and keep track of records 
has features such as refund , and smart json peristance for quick data retrieval 
handles edge cases like low supply, low funds, low shop space etc
allows you to add infinite number of shops, customers and products to stimulate transactions
stores data in a complex oop data structures and keeps a track of data update across the script
mostly optimised for 1 user running the cli.
further updates will be alerted
